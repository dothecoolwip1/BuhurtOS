- **Read by**: `text layer` = the PDF's own text; `OCR n p` = n pages are images of text, read by tesseract 5.3.4 (300 dpi). Layout read from the page
  image: bullet glyphs (●/○), the coloured edge band (dropped), lettering inside pictures (set aside as furniture, every line listed in the structured file).
- **Structure**: provisions use the document's own numbering only. Tables were transcribed cell by cell from the page; the importer refuses a table
  whose cells do not hold exactly the words of the source lines. Picture pages are provisions with an EMPTY body (BuhurtOS writes no words into official text).
- **Review**: reviews were recorded by Claude Code during the import, against rendered page images, and are bound to each provision's content hash
  (a changed text goes back to "needs review"). OCR fixes are listed with the reading they replace and the reason; each must still match the OCR
  output exactly or the import fails.
- **Reconciliation**: every non-empty source line is in exactly one provision or recorded as furniture (table of contents, page footers, repeated
  headers, picture lettering); coverage = provision characters / source characters (table layout marks excluded).
- **DB state**: loaded by migration `20261018000400_rules_bi_2026_10_06.sql` as versions **in review**. Nothing is published until the platform owner
  publishes (Platform › Rules and suspensions). The hosted database is unchanged.
