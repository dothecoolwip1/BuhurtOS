# Event devices: the day-of crib sheet (Pack 18.1)

For Garrett (or whoever runs the event). No developer tools needed. Eight phones/tablets can work the tournament **without personal BuhurtOS accounts**.

## The eight devices (the Red Deer Rumble set)
| Device | Role you pick | It opens on | It can do | It can NOT do |
| --- | --- | --- | --- | --- |
| Counter Phone 1-4 | Counter | the counter screen | count taps for its own fight, privately | anything else; never sees other counters |
| Secretary / Scorekeeper Tablet | Secretary / Scorekeeper | Command Centre (read only) | score and run the Lyst, call fights, move the running order, send announcements, turn the cameras OFF | build the schedule, fix results, change settings, turn cameras back ON, run the broadcast |
| Marshal Phone | Marshal | its Lyst screens | run its Lyst, call fights, turn the cameras OFF | reorder the queue, announce, read the Command Centre, turn cameras back ON |
| Announcer Tablet | Announcer | the Announcer screen | read live fights, scores, up next, results; turn the cameras OFF | everything else (it is read only) |
| Event Admin Tablet | Event Admin / Temporary Organizer | Command Centre | almost everything an organizer does **inside this one event**: results, queue, announcements, broadcast controls, cameras off AND on, staff (not organizers) | create or revoke device codes, change event settings, make organizers, see emails or medical notes, touch any other event |

A device belongs to **one event**, has **one role**, is **not a person** (no profile, no fighter, no team) and stops working by itself **24 hours after the event's last day ends** (in the event's time zone). It never needs a code entered again during the event.

## Before the event (organizer, on a phone or laptop)
1. Command Centre → **Event devices** → **Add the usual set** (or add one by one: name + role).
2. The codes (and a QR for each) are shown **once**. Print the sheet or screenshot it. BuhurtOS cannot show a code again. A lost code is fixed by **Replace**, not by looking it up.
3. Hand each device its own card. Do not share one code between devices (the second sign-in signs the first one out and you will see "signed in on another device").
4. On each device: open the app (installed or in the browser) → **/device** (or scan the QR) → enter the code. The device bar then says, for example: **RED DEER RUMBLE · Temporary Device · Marshal Phone · Role: Marshal · access ends Mon 12:00 AM**.
5. iPhones/iPads: if you install BuhurtOS to the Home Screen, enter the code **again inside the installed app** (Safari and the installed app do not share a sign-in).
6. Check each device once: it lands on its screen; the bar shows the right name and role.

## During the event
- Nobody enters a code again. Closing and reopening the app, sleeping the phone, a refresh: all stay signed in.
- **A phone goes missing:** Command Centre → Event devices → that device → **Revoke**. Only that phone stops (within seconds). Everyone else keeps working. Then **Replace** if you want the same name back with a new code.
- **A code was photographed or shared by mistake:** **Replace** it. The old code and any session on it die immediately.
- **Something looks wrong with all devices:** **Sign out all temporary devices** (organizer only). Then sign each device in again with its (replaced) code.
- A device shows "This device's access has ended": it was revoked or expired. Ask the organizer for a new code.

## Emergency camera off (everyone on the list above except Counters can do this)
Tap **CAMERA OFF**, then tap why (Medical / injury is first). The stream switches to the safe screen right away. The fight and the scoring carry on.
The screen then says **CAMERAS OFF · activated by (who) · time · waiting for authorized release**. Only the **head marshal**, the **Event Admin**, an **organizer** or the platform owner can turn the cameras back on. It stays off through new fights, restarts and a lost internet connection until one of them releases it.

## Not the right tool
Counters do not get Camera Off. The Announcer cannot score. Event Admin cannot create device codes (that is the organizer's job, so a lost admin tablet cannot hand out new access).
