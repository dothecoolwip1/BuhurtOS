https://www.buhurtinternational.com/rules. They were transcribed on 2026-10-06 from PDF copies in the
owner's Google Drive folder "BuhurtOS Pack22 Upload Temp". **The original PDFs are authoritative.**
These copies make the text searchable for product work; they do not replace the originals.

## Known limitations

- Text was extracted as plain text, so images, logos and strikethrough formatting were lost. In Marshal
  Jobs, the uniform and belt-flag pictures survive only as captions.
- The League Structure tables were rebuilt from flattened text. Check where values sit in each column
  against the PDF before relying on them.
- Several documents have contents pages or cross-references that don't match their body numbering.
  These are kept as printed and flagged in each file's transcriber notes.
- This set may not include every document on the BI rules page. The site itself could not be reached
  from the environment that made these copies, so the list has not been checked against it.
